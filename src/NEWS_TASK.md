# 오늘의 뉴스 만들기 (매일 예약 작업이 따르는 절차)

3분 영어 앱의 "오늘의 뉴스" 칸에 들어갈 파일을 **하루 2개** 만든다.

| 종류 | 파일 | 내용 |
|---|---|---|
| 경제 | `news/<날짜>.json` | 비즈니스·무역·물류 뉴스 |
| 핫이슈 | `news/<날짜>-hot.json` | 해외 화제·트렌드 뉴스 |

학습자는 한국 무역·물류 회사의 실무 담당자이고, 영어 수준은 CEFR A2–B1이다.

## 0. 시작
- 오늘 날짜는 한국 시간 기준이다: `TZ=Asia/Seoul date +%F`
- 저장소 맨 위 폴더에서 작업한다. 먼저 `git pull`로 main을 최신으로 맞춘다.
- 두 파일이 모두 이미 있으면 아무것도 바꾸지 말고 "이미 있음"으로 끝낸다.
- 하나만 있으면 없는 쪽만 만든다.

## 1. 뉴스 고르기 (실제 뉴스만 쓴다)

### 경제 뉴스 1개
- 최근 48시간 안에 나온 비즈니스·무역·물류 뉴스에서 고른다.
  - 예: 해상·항공 운임, 항만, 관세, 환율, 공급망, 수출입 통계, 원자재 가격
- 이 학습자의 업무에 쓸모 있는 기사를 고른다.

### 핫이슈 뉴스 1개
- 최근 48시간 안에 해외에서 화제가 된 소식에서 고른다.
  - 예: 기술·신제품, 인공지능, 문화·영화·음악, 스포츠, 여행, 화제의 소식, 생활 트렌드
- 거래처와 가볍게 이야기 나눌 만한(스몰토크) 주제를 고른다.
- **피할 것:** 사고·참사·범죄, 편이 갈리는 정치·종교, 선정적인 내용

### 두 뉴스 공통
- 믿을 만한 언론사를 우선한다.
  - 해외: Reuters, AP, BBC, Bloomberg, CNBC, The Verge, ESPN 등
  - 국내 영문: Yonhap, Korea Herald
  - 물류 전문: JOC, Lloyd's List, Splash247, Freightos 등
- 사실 확인은 웹 검색(WebSearch) 결과로 한다. 이 작업 환경은 뉴스 사이트 직접 접속(WebFetch)이 막혀 있을 수 있다.
  - 같은 뉴스를 다룬 검색 결과를 2개 이상 찾아, 두 곳 이상에서 일치하는 사실만 쓴다.
  - 사실이 부족하면 같은 사건으로 검색을 1~2번 더 한다.
  - WebFetch가 되는 사이트면 원문을 읽어도 된다. 막히면 다시 시도하지 말고 검색 결과만 쓴다.
- `sources`에는 검색 결과에 나온 실제 기사 주소(https)를 1~3개 적는다. 주소를 지어내지 않는다.
- 숫자, 날짜, 회사명, 인명은 출처에 있는 그대로 쓴다.
  - 출처끼리 숫자가 다르면 그 숫자는 빼거나 "about"으로 쓴다.
  - 지어내지 않는다.
- 두 곳 이상에서 확인되는 뉴스를 못 찾은 종류는 만들지 않고, 그 이유를 보고한다.

## 2. 쉬운 영어로 새로 쓰기 (저작권)
- 원문 문장을 복사하지 않는다. 원문에서 6단어 이상 연속으로 똑같이 가져오지 않는다(고유명사 제외).
- 내 말로 다시 쓴다.
  - 2~3문단, 모두 합쳐 120~170단어.
  - 짧은 문장, 쉬운 단어(A2–B1).
  - 첫 문단에 핵심을 쓴다.

## 3. 파일 형식 (UTF-8)
`news/<날짜>.json` 또는 `news/<날짜>-hot.json`

```json
{
  "date": "2026-11-18",
  "kind": "biz",
  "title": "Short English title",
  "title_ko": "한국어 제목",
  "paras": ["첫 문단(영어)", "둘째 문단(영어)"],
  "paras_ko": ["첫 문단의 자연스러운 한국어 번역", "둘째 문단 번역"],
  "sources": [{"name": "Reuters", "url": "https://...", "published": "2026-11-17"}],
  "qs": [
    {"q": "What is the main point of this news?", "opts": ["...", "...", "..."], "a": 1, "why_ko": "정답 근거(짧은 한국어)"},
    {"q": "...", "opts": ["...", "...", "..."], "a": 0, "why_ko": "..."},
    {"q": "...", "opts": ["...", "...", "..."], "a": 2, "why_ko": "..."}
  ],
  "words": [
    {"en": "freight rate", "ko": "운임", "easy": "shipping price", "ex": "Could you check the freight rate for next month?", "ex_ko": "다음 달 운임을 확인해 주시겠어요?", "cat": "m"}
  ]
}
```
- `kind`는 경제 뉴스면 `"biz"`, 핫이슈면 `"hot"`이다.
- `words`의 발음기호(`ipa`)는 직접 쓰지 않는다. 4단계의 `news_audio.py`가 자동으로 채운다.

### 문제 `qs` (정확히 3개)
- 1번은 "이 뉴스의 핵심은?"을 묻는다. 2·3번은 본문 속 세부 내용을 묻는다.
- 질문은 쉬운 영어로 쓴다. 보기는 3개다.
- 정답 위치(a = 0~2)는 문제마다 섞는다.
- 정답은 본문만 읽고 고를 수 있어야 한다.

### 단어 `words` (정확히 5개)
- 본문에 실제로 나온 단어나 표현을 고른다. 쓸모 있고 조금 어려운 것으로 고른다.
- `ex`는 학습자가 그대로 쓸 수 있는 짧은 새 문장이다. 그 단어를 꼭 넣는다.
  - 경제 뉴스: 메일·전화·회의에서 쓰는 업무 문장
  - 핫이슈 뉴스: 거래처와 나누는 스몰토크 문장(예: "Did you hear about ~?")
- `easy`는 같은 뜻의 더 쉬운 영어 단어나 짧은 표현이다(A2 수준, 예: purchase → buy). 이미 쉬운 단어면 비슷한 쉬운 말을 적는다.
- `cat`은 그 예문을 쓰는 곳이다: `m` 메일, `p` 전화, `t` 회의.
  - 스몰토크 예문은 보통 `p`나 `t`다.

## 4. 음성·발음기호 만들기와 검사 (파일마다)
```bash
pip install -q kokoro-onnx soundfile phonemizer espeakng-loader   # 이미 있으면 건너뜀
python3 src/news_audio.py news/<파일이름>.json
python3 src/check_news.py news/<파일이름>.json
```
- 검사가 실패하면 고치고 다시 검사한다. 통과하면 `news/index.json`이 갱신된다.
