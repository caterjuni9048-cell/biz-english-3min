# 오늘의 뉴스 만들기 (매일 예약 작업이 따르는 절차)

3분 영어 앱의 "오늘의 뉴스" 칸에 들어갈 파일을 만든다.
학습자는 한국 무역·물류 회사의 실무 담당자이고, 영어 수준은 CEFR A2–B1이다.

## 0. 시작
- 오늘 날짜는 한국 시간 기준이다: `TZ=Asia/Seoul date +%F`
- 저장소 맨 위 폴더에서 작업한다.
- `news/<오늘 날짜>.json`이 이미 있으면 아무것도 바꾸지 말고 "이미 있음"으로 끝낸다.

## 1. 뉴스 고르기 (실제 뉴스만 쓴다)
- 웹 검색으로 최근 48시간 안에 나온 비즈니스·무역·물류 뉴스를 찾는다.
  - 예: 해상·항공 운임, 항만, 관세, 환율, 공급망, 수출입 통계, 원자재 가격
- 이 학습자의 업무에 쓸모 있는 기사 1개를 고른다.
- 믿을 만한 언론사를 우선한다.
  - 해외: Reuters, AP, BBC, Bloomberg, FT, CNBC, Nikkei Asia
  - 국내 영문: Yonhap, Korea Herald
  - 물류 전문: JOC, Lloyd's List, Splash247, Freightos 등
- 기사 원문을 읽고(WebFetch), 가능하면 다른 출처 1개로 사실을 한 번 더 확인한다.
- 출처에 나온 사실만 쓴다. 숫자, 날짜, 회사명, 인명은 출처 그대로 쓴다.
  - 출처끼리 숫자가 다르면 그 숫자는 빼거나 "about"으로 쓴다.
  - 지어내지 않는다.
- 쓸 만한 뉴스를 못 찾았거나 검색·읽기가 안 되면, 파일을 만들지 않고 이유를 보고하고 끝낸다.

## 2. 쉬운 영어로 새로 쓰기 (저작권)
- 원문 문장을 복사하지 않는다. 원문에서 6단어 이상 연속으로 똑같이 가져오지 않는다(고유명사 제외).
- 내 말로 다시 쓴다.
  - 2~3문단, 모두 합쳐 120~170단어.
  - 짧은 문장, 쉬운 단어(A2–B1).
  - 첫 문단에 핵심을 쓴다.

## 3. 파일 형식: `news/<날짜>.json` (UTF-8)
```json
{
  "date": "2026-11-16",
  "title": "Short English title",
  "title_ko": "한국어 제목",
  "paras": ["첫 문단(영어)", "둘째 문단(영어)"],
  "paras_ko": ["첫 문단의 자연스러운 한국어 번역", "둘째 문단 번역"],
  "sources": [{"name": "Reuters", "url": "https://...", "published": "2026-11-15"}],
  "qs": [
    {"q": "What is the main point of this news?", "opts": ["...", "...", "..."], "a": 1, "why_ko": "정답 근거(짧은 한국어)"},
    {"q": "...", "opts": ["...", "...", "..."], "a": 0, "why_ko": "..."},
    {"q": "...", "opts": ["...", "...", "..."], "a": 2, "why_ko": "..."}
  ],
  "words": [
    {"en": "freight rate", "ko": "운임", "ex": "Could you check the freight rate for next month?", "ex_ko": "다음 달 운임을 확인해 주시겠어요?", "cat": "m"}
  ]
}
```

### 문제 `qs` (정확히 3개)
- 1번은 "이 뉴스의 핵심은?"을 묻는다. 2·3번은 본문 속 세부 내용을 묻는다.
- 질문은 쉬운 영어로 쓴다. 보기는 3개다.
- 정답 위치(a = 0~2)는 문제마다 섞는다.
- 정답은 본문만 읽고 고를 수 있어야 한다.

### 단어 `words` (정확히 5개)
- 본문에 실제로 나온, 업무에 쓸 만한 단어나 표현을 고른다.
- `ex`는 학습자가 메일·전화·회의에서 그대로 쓸 수 있는 짧은 새 문장이다. 그 단어를 꼭 넣는다.
- `cat`은 그 예문을 쓰는 곳이다: `m` 메일, `p` 전화, `t` 회의.

## 4. 음성 만들기와 검사
```bash
pip install -q kokoro-onnx soundfile   # 이미 있으면 건너뜀
python3 src/news_audio.py news/<날짜>.json
python3 src/check_news.py news/<날짜>.json
```
- 검사가 실패하면 고치고 다시 검사한다. 통과하면 `news/index.json`이 갱신된다.

## 5. 올리기
- `news/` 폴더만 커밋한다. 다른 파일은 바꾸지 않는다.
  - 커밋 메시지: `오늘의 뉴스 <날짜>`
- main 브랜치에 push한다. 네트워크 오류가 나면 4번까지 다시 시도한다.
