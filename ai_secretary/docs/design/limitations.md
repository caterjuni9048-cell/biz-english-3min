# limitations.md — 알려진 한계 (사용자 승인 필요)

L01. 카카오톡은 알림으로만 수집한다. 알림이 오지 않은 메시지(PC 카톡 사용 중, 방 알림 끔, 방을 열어 둔 상태)는 놓칠 수 있다. → 앱 화면에 "수집 누락 가능 구간"을 표시하고, 놓친 메시지는 '공유하기'로 직접 넣을 수 있게 한다.
L02. 카톡 사진·파일은 알림에 "사진", "파일"로만 표시된다. 내용은 사용자가 공유하기로 넣어야 한다.
L03. RCS(채팅+) 문자는 완전한 수집이 보장되지 않는다.
L04. 노트북이 꺼져 있는 동안에는 AI 분석과 즉시 보고가 멈춘다. 수집한 자료는 폰에 저장했다가 노트북이 켜지면 이어서 처리한다.
L05. 통화는 녹음 저장이 끝난 뒤에 처리하므로 실시간 보고가 아니다(지연 시간 미확인).
L06. 음성인식은 제품명과 수량을 잘못 알아들을 수 있다. AI가 이를 확정하지 않고 "확인 필요"로 둔다.
L07. 지정 단체방 자동 보고는 V1.0 기본 기능에서 뺀다. 보고는 앱 푸시와 '나와의 채팅'으로 한다.
L08. 앱을 강제 종료하거나 삼성 절전 앱으로 지정하면 수집이 멈출 수 있다. 앱이 이를 감지하면 경고한다(완전한 감지는 미확인).
L09. 외부 AI(Claude API)와 외부 음성인식으로 자료를 보내는 기능은 법적 검토가 끝날 때까지 기본 OFF로 둔다. OFF인 동안에는 로컬 처리만 하거나 분석을 대기시킨다.
L10. 픽셀사무실과는 V1.0에서 모의 연동까지만 한다. 실제 연결은 별도로 승인받는다.
